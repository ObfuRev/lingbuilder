# TCP 与 UDP IPv6 通信演示

一个演示 **TCP 客户端** 与 **UDP 数据报** 在 IPv6（以及 IPv4）下连接、发送、接收的完整示例项目。连接成功与失败都有弹窗提示，详细过程写进底部「运行日志」。

## 使用模块

| 模块 | 用途 |
| --- | --- |
| `lingbuilder.win32.basic` | 控件读写（控件_取文本/设置文本）、到整数/到文本、日志框滚动 |
| `lingbuilder.net.tcp` | TCP_连接 / TCP_发送文本 / TCP_接收文本 / TCP_是否已连接 / TCP_取错误 / TCP_关闭 |
| `lingbuilder.net.udp` | UDP_绑定 / UDP_发送文本 / UDP_接收文本 / UDP_取来源地址 / UDP_取来源端口 / UDP_取错误 |

## 怎么运行

1. 用 LingBuilder IDE 打开本源码包（`.lcpppkg`）所在工作区，或直接把源码包拖进 IDE 导入。
2. 按 **F5** 构建并运行本演示窗口。
3. 按下面两种玩法之一体验。

## 玩法一：TCP 回声测试（附带服务端脚本）

1. 在 `examples/net-ipv6-demo/src/` 目录里找到 **`TCP回声服务器.ps1`**，右键 →「使用 PowerShell 运行」
   （或在命令行执行：`powershell -ExecutionPolicy Bypass -File .\TCP回声服务器.ps1`）。
   它监听 `[::1]:9001`，把收到的每条消息原样发回。
2. 演示窗口保持默认地址 `::1`、端口 `9001`，点 **「连接」**：
   - 成功：弹「TCP 连接成功！」，状态栏变「TCP：已连接」，日志记录全过程。
   - 失败（比如服务端没开）：弹「TCP 连接失败！」，日志写明中文错误原因。
3. 点 **「发送数据」** 把输入框里的文本发给服务端，再点 **「接收数据」** 收回声：
   日志会出现 `TCP 收到：……` 一行，内容与发送的相同。
4. 试失败路径：把端口改成 `19999`（没有服务端的端口）再点「连接」，即可看到失败提示。

## 玩法二：UDP 数据报测试

1. 运行 **`UDP回声服务器.ps1`**（监听 `[::]:9001`，收到数据报原样发回来源地址）。
2. 演示窗口点 **「绑定端口」**（默认绑定本机 `9002`）：状态栏变「UDP：已绑定端口 9002」。
   本演示的 UDP 绑定是 **IPv4/IPv6 双栈**，同一端口两族数据报都能收。
3. 目标地址保持 `::1`、目标端口 `9001`，点 **「发送数据报」**，再点 **「接收数据报」**：
   日志出现 `UDP 收到来自 ::1:xxxxx 的数据：……`。
4. 玩法三：**开两份本演示程序互聊**——第一份本机端口填 `9002`、目标端口填 `9001`；第二份反过来
   （本机端口 `9001`、目标端口 `9002`）。两边分别点「绑定端口」后即可互发数据报。

## IPv6 知识点（代码里怎么体现）

- `TCP_连接` 与 `UDP_发送文本` 都按 **IPv4 + IPv6 双栈解析**目标：填 IPv6 字面量（`::1`）、IPv4
  字面量或域名都行；域名同时有 A 和 AAAA 记录时优先 IPv4，要强制走 IPv6 就直接填 IPv6 字面量。
- `UDP_绑定` 用双栈套接字绑定，同一端口可同时接收 IPv4 与 IPv6 数据报。
- `UDP_取来源地址()` 对 IPv4 对端返回点分十进制（如 `127.0.0.1`），对 IPv6 对端返回数字形式（如 `::1`）。
- 想测公网 IPv6：把地址改成对方的 IPv6 地址即可（两端至少一方要有 IPv6 网络）。

## 控件与命令速查

- 读用户输入：`控件_取文本(控件名)`；写界面文本：`控件_设置文本(控件名, 内容)`；日志追加用「取文本 + 拼接 + 设置文本」三步，`"\n"` 换行在多行编辑框里自动生效。
- 端口校验：`到整数(控件_取文本(...))` 后判断 `1~65535`（UDP 本机端口允许 0=系统分配）。
- TCP 接收没有数据时会阻塞等待，最长时间＝连接时传的超时毫秒（本演示 2000 毫秒）；UDP 接收超时是独立参数 `UDP_接收文本(最大字节, 超时毫秒)`。
